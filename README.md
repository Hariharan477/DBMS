# DBMS Laboratory Experiments

This repository contains DBMS lab programs covering SQL, PL/SQL, and NoSQL concepts.

## Experiments

| File | Description |
|------|-------------|
| [Ex01_Table_Creation_Queries.sql](Ex01_Table_Creation_Queries.sql) | Table Creation, Simple Queries, Nested Queries & Subqueries |
| [Ex02_Joins.sql](Ex02_Joins.sql) | Inner Join, Left Join & Right Join |
| [Ex03_Views_Indexes.sql](Ex03_Views_Indexes.sql) | Views, DML Operations & Indexes |
| [Ex04_Cursors.sql](Ex04_Cursors.sql) | Implicit & Explicit Cursors |
| [Ex05_Procedures_Functions.sql](Ex05_Procedures_Functions.sql) | Stored Procedures & Functions |
| [Ex06_Triggers.sql](Ex06_Triggers.sql) | Triggers (Update, Delete, Insert) |
| [Ex07_Library_Tables.sql](Ex07_Library_Tables.sql) | Library Database Schema (Authors, Books, Borrowers) |
| [Ex08_Exceptions.sql](Ex08_Exceptions.sql) | Pre-defined & User-defined Exceptions |
| [Ex09_NoSQL_Examples.md](Ex09_NoSQL_Examples.md) | NoSQL Examples (Redis, Cassandra, MongoDB, Neo4j) |
| [Ex10_MongoDB_Library.js](Ex10_MongoDB_Library.js) | MongoDB Library CRUD Operations |

## Topics Covered
- Relational Database Design
- SQL Queries (Simple, Nested, Subqueries)
- Joins
- Views & Indexes
- PL/SQL Cursors, Procedures, Functions, Triggers & Exceptions
- NoSQL Databases (Key-Value, Column, Document, Graph)
